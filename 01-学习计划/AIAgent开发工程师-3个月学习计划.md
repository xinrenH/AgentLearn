# AIAgent开发工程师 3个月学习计划（12周）

## 1. 目标与原则
- 目标：12周内完成从“会调用模型”到“可独立开发上线Agent系统”。
- 原则：每周必须有可演示产出，不只学概念。
- 验收标准：至少完成3个可运行项目 + 1份完整作品集文档。

## 2. 技术栈建议（默认）
- 语言与后端：Python + FastAPI
- 数据层：PostgreSQL + Redis
- 检索层：向量库（FAISS/pgvector/Milvus任选其一）
- 模型接口：OpenAI兼容API + Tool Calling
- 部署与运维：Docker + Linux + 基础CI/CD
- 观测：日志、指标、成本统计（token/请求）

## 3. 12周分阶段计划

## 第1阶段：基础补齐（第1-4周）
### 第1周：工程基础与API能力
- 学习内容：Python进阶（异步、类型标注）、HTTP、REST、FastAPI基础。
- 实践任务：实现一个多接口API服务（用户、任务、日志）。
- 周产出：
  - 可运行FastAPI项目
  - README（启动方式、接口说明）
- 验收：能独立完成API开发、调试、日志排查。

### 第2周：LLM基础与提示词工程
- 学习内容：Token、上下文窗口、采样参数、系统提示词、few-shot、结构化输出。
- 实践任务：实现“结构化问答助手”（输出JSON，含字段校验）。
- 周产出：
  - Prompt模板库（至少10个模板）
  - Prompt版本记录表（V1/V2对比）
- 验收：同一任务可稳定输出可解析JSON。

### 第3周：RAG基础链路
- 学习内容：文档清洗、切块、Embedding、向量检索、TopK与阈值。
- 实践任务：搭建一个本地知识库问答Demo。
- 周产出：
  - 数据处理脚本
  - 检索服务与问答接口
- 验收：问题可追溯到引用片段，错误率可观测。

### 第4周：RAG优化与评测
- 学习内容：重排（rerank）、召回率、准确率、延迟与成本优化。
- 实践任务：为第3周项目加入评测集（50-100条）。
- 周产出：
  - RAG评测报告（命中率/事实性/延迟）
  - 优化前后对比数据
- 验收：至少完成2项可量化优化。

## 第2阶段：Agent能力构建（第5-8周）
### 第5周：Tool Calling与工作流编排
- 学习内容：函数调用、工具注册、参数校验、错误重试。
- 实践任务：做一个“工具型Agent”（搜索+数据库+计算工具）。
- 周产出：
  - 工具调用日志
  - 失败重试与回退策略
- 验收：工具调用成功率>90%（测试集）。

### 第6周：Agent核心循环（Plan-Act-Reflect）
- 学习内容：任务分解、执行步骤控制、反思纠错。
- 实践任务：实现“多步骤任务Agent”（例如自动生成周报）。
- 周产出：
  - 任务状态机设计文档
  - 执行轨迹可视化日志
- 验收：多步骤任务可稳定完成并可追踪。

### 第7周：记忆与会话管理
- 学习内容：短期记忆、长期记忆、会话摘要、记忆召回策略。
- 实践任务：给Agent加入用户偏好记忆与历史任务记忆。
- 周产出：
  - 记忆存储结构设计
  - 记忆命中示例与误召回分析
- 验收：连续对话中能正确复用关键历史信息。

### 第8周：多Agent协作（可选增强）
- 学习内容：角色分工（规划者/执行者/审查者）、并行协作、冲突解决。
- 实践任务：实现双Agent协作完成复杂任务。
- 周产出：
  - 协作流程图
  - 单Agent vs 多Agent对比报告
- 验收：复杂任务完成质量明显提升。

## 第3阶段：生产化与作品集（第9-12周）
### 第9周：安全与权限
- 学习内容：Prompt Injection防护、工具权限隔离、敏感信息脱敏。
- 实践任务：为现有Agent加入安全网关与审计日志。
- 周产出：
  - 安全策略清单
  - 攻击测试用例（10+）
- 验收：常见注入攻击可拦截并记录。

### 第10周：监控与评测体系
- 学习内容：线上指标（成功率、延迟、成本、满意度）、离线评测。
- 实践任务：接入监控面板与告警阈值。
- 周产出：
  - 指标看板
  - 周度质量报告模板
- 验收：可定位性能瓶颈与失败原因。

### 第11周：项目1和项目2打磨
- 学习内容：工程化重构、接口稳定性、异常治理。
- 实践任务：完成以下2个项目可演示版本：
  - 企业知识库问答Agent（RAG）
  - 工单自动处理Agent（分类、分派、回复建议）
- 周产出：
  - 演示脚本
  - 部署文档
- 验收：可在新环境按文档一键启动。

### 第12周：项目3 + 作品集封装
- 学习内容：对外表达与技术叙事（面试表达）。
- 实践任务：完成“代码助手Agent”并整理完整作品集。
- 周产出：
  - 3个项目源码链接
  - 架构图、评测数据、优化前后对比
  - 个人简历中的Agent项目描述（STAR）
- 验收：可用于面试演示与技术答辩。

## 4. 每周固定节奏（建议）
- 周一到周三：学习与最小原型。
- 周四到周五：功能补齐与测试。
- 周六：复盘、写文档、录演示视频。
- 周日：查漏补缺 + 下周计划。

## 5. 必做清单（转岗成功关键）
- 每周至少一次“可运行演示”，避免只记笔记。
- 所有项目必须有评测数据，不只展示效果图。
- 所有项目必须包含错误处理和日志追踪。
- 至少准备20个常见面试问答（RAG、Agent、安全、成本）。

## 6. 面试前两周冲刺
- 项目复盘：每个项目准备“问题-方案-结果-指标”。
- 系统设计：准备1道Agent架构设计题（高并发+低成本）。
- 手写能力：准备2道API实现题 + 1道检索链路题。

## 7. 你可以直接开始的第一步（今天）
- 创建一个 `agent-learning-lab` 仓库。
- 完成 FastAPI + 模型调用 + 结构化输出的最小Demo。
- 同时建立一份 `metrics.md`，从第一天开始记录成功率、延迟、成本。

---
最后标准：你不是“会用AI工具”，而是“能把Agent做成稳定可交付系统”的工程师。
