## 题目、作答、标准答案与解析

### 1. 你项目里 `GET /` 返回 404，为什么这通常不代表服务崩溃？
- 我的答案：主目录还没挂载路由，需要转到 `/health` 或 `/docs`，如果 `/health` 显示 `status: OK` 就正常。
- 正确答案：`/` 路由未定义时返回 404 是正常现象，只代表“该路径不存在”。只要健康检查接口（如 `/health`）正常返回（本项目为 `{"status":"ok"}`），说明服务进程是正常运行的。
- 解析：HTTP 404 是路由层语义，不等于服务异常。排查顺序应先看健康检查，再看日志与进程状态。

### 2. `app/main.py` 里 `app.include_router(api_router, prefix=settings.api_prefix)` 的作用是什么？
- 我的答案：应该是引入路由目录，将 router 中的路由挂载。
- 正确答案：将 `api_router` 下聚合的所有子路由统一注册到应用，并自动加上公共前缀（例如 `/api`）。
- 解析：这样可统一管理版本和命名空间，避免每个路由重复写前缀，后续改前缀只改一处配置。

### 3. 为什么 `APP_` 前缀能减少环境变量污染问题？
- 我的答案：加了前缀后项目根据对应前缀引入。
- 正确答案：通过 `env_prefix="APP_"` 仅读取以 `APP_` 开头的变量，避免误读系统/其他项目同名变量。
- 解析：例如系统里存在 `DEBUG=release`，若不加前缀可能污染本项目配置。加前缀后只读取 `APP_DEBUG`。

### 4. 内存仓储和 PostgreSQL 持久化的本质差别是什么？
- 我的答案：内存仓储是存在磁盘中，关机清空；SQL 持久化存数据库。
- 正确答案：内存仓储是进程内存（RAM），进程重启即丢；PostgreSQL 是持久化到数据库存储，服务重启后数据仍在。
- 解析：内存仓储适合 Demo 与快速验证，不适合正式数据保存。

### 5. 在任务状态更新接口里，为什么要限制 `status` 枚举值而不是任意字符串？
- 我的答案：不确定，可能是枚举可遍历所有接口状态。
- 正确答案：保证数据合法性与状态机一致性，防止出现非法状态值（如 `finished`、`abc`），降低业务分支和排错成本。
- 解析：状态字段是业务约束核心，必须在入参层就拦截非法值。

### 6. Tool Calling 中，LLM 和你本地 Python 代码各自负责什么？
- 我的答案：不知道。
- 正确答案：LLM 负责“决定调用哪个工具、传什么参数”；本地 Python 负责“真实执行工具并返回结果”。
- 解析：LLM 不会直接访问你的数据库/系统命令，它只输出调用建议（tool call）。

### 7. `tool_calls` 返回后，正确的下一步处理流程是什么？
- 我的答案：对 tools 获取的数据处理后发送前端。
- 正确答案：收到 `tool_calls` -> 本地执行对应工具 -> 把工具结果作为 `tool message` 回填给模型 -> 模型基于结果生成最终回复。
- 解析：这是完整协作闭环。不是直接发前端，而是先回填给 LLM 形成最终答案。

### 8. RAG 里 `chunk_size` 过大和过小各会导致什么问题？
- 我的答案：过大可能混入不同知识；过小会把同一知识拆散，导致相似度下降。
- 正确答案：基本正确。过大降低检索精度并引入噪声；过小损失上下文完整性，召回可能不稳定。
- 解析：`chunk_size` 需要按文档类型与问答粒度调参，通常配合 `chunk_overlap`。

### 9. 为什么 RAG 要设置“相似度阈值”，而不是永远返回 top-k？
- 我的答案：最相似不一定正确。
- 正确答案：top-k 只代表“相对最像”，不代表“足够相关”。阈值用于拒绝低质量召回，减少幻觉。
- 解析：无阈值时模型会拿低相关片段硬回答，事实性下降。

### 10. 当知识库没有命中内容时，系统应该怎么回复才算正确？
- 我的答案：需要联网查询并说明来源。
- 正确答案：默认应明确告知“知识库无相关信息/未命中”，并拒绝编造；仅在系统显式配置了联网工具时，才进入外部检索流程。
- 解析：这是“先保证真实性，再扩展能力”的原则。
