## 详细实操步骤

### Step 0：启动服务
1. 进入项目目录：`D:\AIAgent\AgentLearn\Demo1`
2. 启动服务（任选其一）：
   - `.\start.ps1`
   - 或 `uvicorn app.main:app --reload`
3. 浏览器访问：
   - `http://127.0.0.1:8000/health`（预期：`status=ok`）
   - `http://127.0.0.1:8000/docs`（Swagger 页面可打开）

### Step 1：验证 `POST /api/tasks` 参数校验（422）
1. 在 Swagger 找到 `POST /api/tasks`，点击 `Try it out`。
2. 请求体输入非法数据（示例）：
```json
{
  "title": ""
}
```
3. 点击 `Execute`。
4. 记录：
   - 返回状态码应为：`422`
   - 响应体应包含：`detail`（校验错误信息）

### Step 2：验证 `PATCH /api/tasks/{task_id}/status` 状态枚举校验（422）
1. 先创建一条合法任务：`POST /api/tasks`
```json
{
  "title": "学习Day2校验"
}
```
2. 在 `PATCH /api/tasks/{task_id}/status` 点击 `Try it out`。
3. `task_id` 填刚创建的 id，请求体填非法状态：
```json
{
  "status": "finished"
}
```
4. 点击 `Execute`。
5. 记录：
   - 返回状态码应为：`422`
   - 响应体应提示 `status` 不在允许值中

### Step 3：验证 `PATCH /api/tasks/{task_id}/status` 不存在资源（404）
1. 在同一接口中把 `task_id` 改为明显不存在值（示例：`99999`）。
2. 请求体使用合法状态：
```json
{
  "status": "done"
}
```
3. 点击 `Execute`。
4. 记录：
   - 返回状态码应为：`404`
   - 响应体应包含：`detail: "task not found"`（以代码实际返回为准）

### Step 4：最小回归（确认服务未被错误修改）
1. 调用 `GET /api/tasks`。
2. 预期：接口正常返回（200），服务仍可用。
